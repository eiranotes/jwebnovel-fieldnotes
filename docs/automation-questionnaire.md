## Recommended initial answers

확신이 없으면 아래로 시작하는 것을 권장:

- 300,000자 기본 + high-fit length exception 최대 2편
- shortlist 10편 / source pipeline top 5
- 연재중 > 완결 > 중단
- commercial publication은 profile별 설정
- 후보 재노출 30일
- 청크 9,000자 목표 / 12,000자 hard max
- 번역은 오래된 pending 먼저
- GitHub에는 본문 비공개
