# 2026-09-06-02 — 죽음이 일상이 된 플레이어들

## Request snapshot

기준작은 **鵜飼有志 『死亡遊戯で飯を食う。』**. 비슷한 소설을 나로우·카쿠요무에서 찾는다.

이 엔트리는 같은 날 진행한 `2026-09-06-01`과 별개다. 앞선 조사의 `50만 자 이상`, `하이/로우 판타지`, `전생 제외`, `비출판` 조건은 상속하지 않았다. 이후 저장소 전역 정책이 v0.4로 바뀌면서 **사용자 지정 분량이 없을 때 30만 자 이상을 기본 탐색 하한**으로 적용했다. 30만 자 미만은 분량 외 핵심 조건이 매우 강하게 맞을 때만 `LENGTH EXCEPTION`으로 별도 유지한다.

이번에는 설정어 `デスゲーム`보다 다음 독서 감각을 우선한다.

- 죽음의 게임이 일회성 재난이 아니라 **경력·수입·산업**으로 정규화되어 있다.
- 경험자가 공포보다 **규칙·자원·동선·인원수**를 먼저 본다.
- 게임을 여러 번 치르며 참가자 사이의 평판·관계·서열이 누적된다.
- 살벌한 상황과 일상적인 대화가 같은 온도에서 붙는다.
- 승패 뒤에도 다음 게임과 일상이 남는다.

## Reference

### 死亡遊戯で飯を食う。

- Author: 鵜飼有志
- Official: https://www.kadokawa.co.jp/product/322207001275/
- Local sample used: volume 2, opening / ~1/3 / ~2/3

2권에서 유키는 폐건물에서 눈을 뜨자 환경, 타이머, 지급품, 광원, 살상 가능한 도구를 순서대로 확인한다. 다른 참가자를 만난 뒤에도 `몇 번째 게임인가`, 상대의 경험치가 어느 정도인가를 바로 계산한다.

중반의 팀전에서도 인원수, 신발표 수, 샤워실 수, 평균 생환율, 적 팀의 다음 행동을 실무 문제처럼 다룬다. 죽음이 특별하지 않다는 뜻이 아니라, **프로 플레이어의 관점이 죽음을 처리하는 방식 자체가 다르다.**

## Shortlist — 300,000자 이상

### A1. 紅さんはデスゲーマー

- Kakuyomu / ニッケン
- 351,428자 / 115화 / 연재중
- https://kakuyomu.jp/works/1177354054934389837

**줄거리.** 100년 뒤에도 데스게임이 수요를 가진 세계. 여성 데스게이머 `紅`의 게임과 일상을 따라간다. 장기적으로는 게임마스터 역할까지 다룬다.

**왜 가깝나.** `데스게이머의 일상`이라는 전제가 기준작과 직접 겹친다. 한 번의 납치 사건이 아니라 여러 게임의 경험이 축적되고, 플레이어로서의 경력과 운영 측 시각도 생긴다.

**차이.** 문장과 장면 긴장은 기준작보다 거칠고 개그 쪽으로 흔들리는 구간이 많다.

### A2. 拝啓、明日ノ私〜才能で選別される狂気のデスゲーム〜

- Kakuyomu / 廃れ
- 466,846자 / 140화 / 연재중
- https://kakuyomu.jp/works/16818622175556728824

**줄거리.** 재능에 따라 인간의 가치가 정해지는 세계에서 `부적합자`들이 섬으로 보내져 여러 심리·두뇌 데스게임을 치른다.

**근접점.** 참가비와 상금, 승패 기록이 있고 게임마다 별도 룰이 붙는다. 룰을 읽은 뒤 바로 확정승 전략·배신 가능성·협상 비용을 계산하는 장면이 많다.

**차이.** 생업보다는 심리전과 `광기` 캐릭터가 중심이다.

### B1. Redo -リドゥ-

- Kakuyomu / くろぬか
- 706,483자 / 248화 / 완결
- https://kakuyomu.jp/works/16818023213480370601

**줄거리.** 가족의 치료비가 필요한 남자가 목숨을 건 게임 `Redo`에서 포인트를 벌고 현실 돈으로 환전한다.

**근접점.** 획득 포인트를 가족에게 송금하고, 장비 강화에 쓸 자원과 생활비를 분리한다. 승리가 그대로 수입이 되는 루프가 선명하다.

**차이.** 남성 주인공, VR/아바타, 전투형 파워 판타지 성격이 강하다.

## Current conclusion

현재 기준으로 가장 먼저 확인할 순서는:

1. **紅さんはデスゲーマー** — 장기 연재로 `직업 데스게이머` 구조를 가장 많이 검증할 수 있음.
2. **拝啓、明日ノ私** — 46만 자가 넘고 여러 게임과 룰 계산 쪽에서 강함.
3. **Redo -リドゥ-** — 70만 자가 넘으며 게임 수입이 현실 생활비로 이어지는 루프가 선명함.

분량 예외로는 **逆さの茶笠**과 **デスゲーム界の十傑**만 남긴다. 둘 다 30만 자에는 크게 못 미치지만, 이번 기준의 핵심 구조와 직접 겹치는 부분이 뚜렷하다.

이번 패스에서는 `데스게임` 태그보다 **반복성 + 직업성 + 숙련자의 정보처리 방식**을 더 강한 검색 키로 보는 게 유효했다.
