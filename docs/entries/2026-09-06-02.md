# 2026-09-06-02 — 죽음이 일상이 된 플레이어들

## Request snapshot

기준작은 **鵜飼有志 『死亡遊戯で飯を食う。』**. 비슷한 소설을 나로우·카쿠요무에서 찾는다.

이 엔트리는 같은 날 진행한 `2026-09-06-01`과 별개다. 앞선 조사의 `50만 자 이상`, `하이/로우 판타지`, `전생 제외`, `비출판` 조건은 상속하지 않았다.

이번에는 설정어 `デスゲーム`보다 다음 독서 감각을 우선한다.

- 죽음의 게임이 일회성 재난이 아니라 **경력·수입·산업**으로 정규화되어 있다.
- 경험자가 공포보다 **규칙·자원·동선·인원수**를 먼저 본다.
- 게임을 여러 번 치르며 참가자 사이의 평판·관계·서열이 누적된다.
- 살벌한 상황과 일상적인 대화가 같은 온도에서 붙는다.
- 승패 뒤에도 다음 게임과 일상이 남는다.

## Reference

### 死亡遊戯で飯を食う。

- Author: 鵜飼有志
- Official: https://www.kadokawa.co.jp/product/322207001275/
- Local sample used: volume 2, opening / ~1/3 / ~2/3

2권에서 유키는 폐건물에서 눈을 뜨자 환경, 타이머, 지급품, 광원, 살상 가능한 도구를 순서대로 확인한다. 다른 참가자를 만난 뒤에도 `몇 번째 게임인가`, 상대의 경험치가 어느 정도인가를 바로 계산한다.

중반의 팀전에서도 인원수, 신발표 수, 샤워실 수, 평균 생환율, 적 팀의 다음 행동을 실무 문제처럼 다룬다. 죽음이 특별하지 않다는 뜻이 아니라, **프로 플레이어의 관점이 죽음을 처리하는 방식 자체가 다르다.**

## Shortlist

### A1. 紅さんはデスゲーマー

- Kakuyomu / ニッケン
- 351,428자 / 115화 / 연재중
- https://kakuyomu.jp/works/1177354054934389837

**줄거리.** 100년 뒤에도 데스게임이 수요를 가진 세계. 여성 데스게이머 `紅`의 게임과 일상을 따라간다. 장기적으로는 게임마스터 역할까지 다룬다.

**왜 가깝나.** `데스게이머의 일상`이라는 전제가 기준작과 직접 겹친다. 한 번의 납치 사건이 아니라 여러 게임의 경험이 축적되고, 플레이어로서의 경력과 운영 측 시각도 생긴다.

**차이.** 문장과 장면 긴장은 기준작보다 거칠고 개그 쪽으로 흔들리는 구간이 많다.

### A2. 逆さの茶笠

- Kakuyomu / 千華
- 10,755자 / 3화 / 연재중
- https://kakuyomu.jp/works/16818622170137414869

**줄거리.** 미스터리와 데스게임을 반복해서 플레이하는 여성 플레이어 `茶笠`의 이야기.

**왜 가깝나.** 3화에서 게임을 마친 뒤 생존률, 현금 보상, 아바타 수리비, 참가비 요금제, 월간 참가 횟수를 통신요금처럼 정산한다. **죽을 수 있는 게임이 생활의 루틴으로 편입된 감각**은 이번 탐색에서 가장 강하게 닮았다.

**차이.** 현재 3화뿐이라 지속성 검증이 안 된다. 아바타 기반이라 실제 육체의 죽음과 동일한 무게인지도 아직 불명확하다.

### A3. デスゲーム界の十傑 ～世界最強の10人によるタイマン～

- Narou / キタナベ
- 24화 / 2022-12-19 이후 중단
- https://ncode.syosetu.com/n3360hy/

**줄거리.** 데스게임이 일상적으로 개최되고, 상금을 생활비로 삼는 사람을 아예 `デスゲーマー`라고 부르는 세계. 세계 랭커 10인이 팀을 꾸려 이세계 강자들과 목숨을 건 1대1전을 치른다.

**왜 가깝나.** 직업명, 랭킹, 클랜, 경력이 사회 구조로 굳어 있다. 인물이 스스로 `職業はデスゲーマー`라고 말한다.

**차이.** 능력자 토너먼트라 탈출·퍼즐·환경 공략보다 전투력 대결의 비중이 높다.

### B1. 拝啓、明日ノ私〜才能で選別される狂気のデスゲーム〜

- Kakuyomu / 廃れ
- 466,846자 / 140화 / 연재중
- https://kakuyomu.jp/works/16818622175556728824

**줄거리.** 재능에 따라 인간의 가치가 정해지는 세계에서 `부적합자`들이 섬으로 보내져 여러 심리·두뇌 데스게임을 치른다.

**근접점.** 참가비와 상금, 승패 기록이 있고 게임마다 별도 룰이 붙는다. 룰을 읽은 뒤 바로 확정승 전략·배신 가능성·협상 비용을 계산하는 장면이 많다.

**차이.** 생업보다는 심리전과 `광기` 캐릭터가 중심이다.

### B2. Redo -リドゥ-

- Kakuyomu / くろぬか
- 706,483자 / 248화 / 완결
- https://kakuyomu.jp/works/16818023213480370601

**줄거리.** 가족의 치료비가 필요한 남자가 목숨을 건 게임 `Redo`에서 포인트를 벌고 현실 돈으로 환전한다.

**근접점.** 획득 포인트를 가족에게 송금하고, 장비 강화에 쓸 자원과 생활비를 분리한다. 승리가 그대로 수입이 되는 루프가 선명하다.

**차이.** 남성 주인공, VR/아바타, 전투형 파워 판타지 성격이 강하다.

### B3. これはデスゲームを見守る簡単なお仕事です。①-入社編-

- Kakuyomu / 三嶋トウカ
- 126,541자 / 56화 / 완결
- https://kakuyomu.jp/works/16817330657080123886

**줄거리.** 월급 100만 엔짜리 고액 구인에 지원한 남자가 데스게임 회사 `Angelies`의 정직원이 된다. 업무는 게임 감시·관리, 때로는 직접 참가.

**근접점.** 월급, 승진, 참가자 관리, 게임 설계, 현장 운영을 회사 업무로 처리한다. `죽음을 업무 언어로 정상화한다`는 축은 매우 가깝다.

**차이.** 플레이어보다 운영자 시점이다.

### B4. 見てるこっちが怖いデスゲーム

- Kakuyomu / キタナベ
- 105,981자 / 57화 / 완결
- https://kakuyomu.jp/works/16818792437644050925

**줄거리.** 데스게임이 합법화된 지 10년. 상금·실력 향상을 위해 젊은 능력자들이 자발적으로 각종 살인 대회에 참가한다.

**근접점.** 참가자에게 등급, 예상 순위, 킬 수, 연승 기록이 붙고 데스게임이 스포츠처럼 굴러간다.

**차이.** 일부 게임 뒤 운영이 참가자를 부활시키기 때문에 죽음의 비가역성이 기준작보다 약하다.

### B5. 〖完結〗彼はデスゲームで最善の結果を求めるようです

- Narou / 仁
- 148,722자 / 50화 / 완결
- https://ncode.syosetu.com/n5703id/

**줄거리.** 낯선 방에 끌려온 참가자들이 데스게임을 시작한다. 다른 사람이 동요하는 동안 주인공은 공략 루트를 만들고 사람과 게임마스터까지 자원으로 이용한다.

**근접점.** 감정보다 최적화와 정보 처리가 먼저인 주인공.

**차이.** 단일 게임 완결형. 기준작의 `프로 경력`과 게임 사이의 일상이 없다.

## Deprioritized

### 一番好きな子を殺さないと脱出できない百合デスゲーム

여성 군상, 네임드 캐릭터 사망, 잔혹한 룰은 맞는다. 하지만 `가장 좋아하는 사람을 죽여야 한다`는 감정 자체가 핵심 엔진이고 단일 게임이라 기준작의 직업적 건조함과는 멀다.

### 現代最強のデスゲーマー、異世界デスゲームでも無双する

`데스게이머`와 반복 게임이라는 표면은 맞지만 이세계 전생·최강·무쌍이 중심. 게임을 생업으로 처리하는 현실적인 마찰보다 파워 판타지 비중이 높다.

### 魔女は魔法少女の夢を見ない

냉정한 여성 주인공이 룰과 시스템을 해킹하는 점은 맞지만, 장식적 묘사와 압도적 강자의 `蹂躙`이 중심이라 기준작의 제한된 자원 속 전문성하고는 결이 다르다.

## Current conclusion

현재 기준으로 가장 먼저 확인할 순서는:

1. **紅さんはデスゲーマー** — 장기 연재로 `직업 데스게이머` 구조를 가장 많이 검증할 수 있음.
2. **逆さの茶笠** — 분량은 극단적으로 짧지만 생활·참가비·보상 루프가 놀랄 만큼 직접적으로 닮음.
3. **デスゲーム界の十傑** — `데스게이머`가 직업·랭킹·클랜으로 제도화된 세계.
4. **拝啓、明日ノ私** — 긴 분량과 여러 게임, 룰 계산 쪽에서 강함.

이번 패스에서는 `데스게임` 태그보다 **반복성 + 직업성 + 숙련자의 정보처리 방식**을 더 강한 검색 키로 보는 게 유효했다.
